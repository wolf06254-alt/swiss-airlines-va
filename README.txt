СОДЕРЖИМОЕ АРХИВА:
  index.html    — главная страница

========================================
  КАК ЗАЛИТЬ НА RENDER (Static Site)
========================================

1. Создай новый сервис на Render:
   → "New +" → "Static Site"

2. Подключи GitHub-репозиторий ИЛИ загрузи файлы напрямую.

3. Укажи настройки:
   - Build Command: оставь пустым (это чистый HTML/CSS/JS)
   - Publish Directory: ./  (корневая папка, где лежит index.html)

4. Нажми "Create Static Site".

========================================
  КАК ИСПРАВИТЬ ПРОБЛЕМУ "НЕ ЗАХОДИТ"
========================================

Проблема 1: СЕРВЕР "СПИТ" (Cold Start)
---------------------------------------
На бесплатном тарифе Render засыпает после 15 мин без посетителей.
Решение — UptimeRobot (бесплатно):

  1. Зарегистрируйся на uptimerobot.com
  2. Добавь мониторинг:
     - Type: HTTP(s)
     - URL: адрес твоего сайта на Render
     - Interval: каждые 5 минут
  3. Сохрани. Сервер теперь не будет засыпать.

Проблема 2: БЛОКИРОВКИ / НЕТ СОЕДИНЕНИЯ
----------------------------------------
Некоторые провайдеры/регионы блокируют подсети Render.
Решение — Cloudflare (бесплатно):

  1. Зарегистрируйся на cloudflare.com
  2. Добавь свой домен (если есть) или используй субдомен Cloudflare
  3. На DNS-записи сайта включи "оранжевое облако" (Proxied)
  4. В разделе SSL/TLS выбери режим "Full"
  5. Дождись обновления DNS (до 24 часов, обычно 5–15 мин)

  Теперь трафик идёт через сеть Cloudflare — блокировки обходятся,
  а сайт грузится быстрее благодаря кэшированию.

Проблема 3: МОБИЛЬНЫЕ УСТРОЙСТВА
---------------------------------
Если у кого-то не заходит с телефона:
  - Попроси попробовать через 4G/5G вместо Wi-Fi
  - Попроси подождать на странице до 1 минуты (сервер может просыпаться)
  - Убедись, что ссылка начинается с https://

  ДОПОЛНИТЕЛЬНЫЕ УЛУЧШЕНИЯ
