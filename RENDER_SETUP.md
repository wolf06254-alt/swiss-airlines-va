# 🇨🇭 Swiss Airlines VA — Инструкция по настройке на Render

## Шаг 1: Создание сервиса

1. Зайди на [dashboard.render.com](https://dashboard.render.com)
2. Нажми **«New +»** → **«Web Service»**
3. Подключи GitHub репозиторий (или выбери **«Deploy an existing project from a URL»**)
4. Render автоматически прочитает `render.yaml` и создаст:
   - Web Service `swiss-airlines-va`
   - PostgreSQL БД `swiss-airlines-db` (free)

> ⚡ Если `render.yaml` не подхватился автоматически — выбери:
> - **Runtime:** Node
> - **Build Command:** `npm install`
> - **Start Command:** `node server.js`

---

## Шаг 2: База данных (бесплатная)

Render создаёт БД автоматически из `render.yaml`.

Если нужно создать вручную:
1. На дашборде нажми **«New +»** → **«PostgreSQL»**
2. Имя: `swiss-airlines-db`
3. Database: `swiss_airlines`
4. Plan: **Free**
5. Нажми **«Create Database»**
6. Скопируй **Internal Database URL** (он понадобится в Шаге 3)

### ⚠️ Важно про бесплатный план:
- Бесплатная PostgreSQL **засыпает после 90 дней неактивности**
- После засыпания даётся **30 дней** чтобы разбудить — потом удаляется
- Чтобы этого не произошло: заходи в админку хотя бы раз в месяц
- Render может присылать предупреждение на email

### Как «разбудить» спящую БД:
1. Зайди на Render → выбери БД `swiss-airlines-db`
2. Нажми кнопку **«Resume»** (если БД заснула)
3. Подожди ~30 секунд пока БД запустится
4. Сервер автоматически переподключится (благодаря нашим патчам в server.js)

## Шаг 3: Переменные окружения (Environment Variables)

После создания сервиса зайди в **Environment** раздел и добавь:

| Ключ | Значение | Примечание |
|------|----------|------------|
| `ADMIN_USERNAME` | `Gregory` | Твой логин админа |
| `ADMIN_PASSWORD` | `123789` | ⚠️ Нажми **«Secret»** чтобы скрыть! |
| `SESSION_SECRET` | *(нажми «Generate»)* | Render сам создаст случайный ключ |
| `DATABASE_URL` | *(автоматически)* | Связывается из БД |
| `NODE_ENV` | `production` | Уже в render.yaml |
| `PORT` | `10000` | Render требует порт 10000 |

### Как добавить переменные:
1. Зайди в **Dashboard** → выбери сервис `swiss-airlines-va`
2. Слева меню → **Environment**
3. Нажми **«Add Environment Variable»**
4. Введи ключ и значение
5. Для пароля: нажми иконку 👁️ → **«Mark as Secret»**
6. Для SESSION_SECRET: нажми **«Generate»** рядом с полем значения
7. Нажми **«Save Changes»** → Render автоматически пересоздаст сервис

## Шаг 4: Health Check

`render.yaml` уже содержит `healthCheckPath: /api/health`.

Render будет автоматически проверять `/api/health` каждые 30 секунд.
Если ответ не 200 — Render перезапустит сервис.

Твой `/api/health` возвращает:
```json
{
  "status": "ok",
  "db": true,
  "dbType": "postgres",
  "pgReconnectAttempts": 0,
  "env": "production"
}
```

Если БД недоступна — `db: false`, но статус всё равно 200 (чтобы Render не убивал сервер пока он пытается переподключиться).

## 🔍 Диагностика проблем

### Анкеты пропали из админки?
1. Зайди в админку → нажми кнопку **«🔍 DB Status»** (красная кнопка в строке фильтров)
2. Появится модалка с:
   - **DB Ready:** true/false — подключена ли БД
   - **Reconnect attempts:** сколько раз сервер пытался переподключиться
   - **Количество записей** в каждой таблице
   - **Последняя анкета** — если она есть, значит данные на месте
3. Если `DB Ready: false` — подожди 10-30 сек, сервер автоматически переподключится
4. Если количество анкет = 0, но последняя анкета показана — значит данные есть, просто запрос не отработал

### Сервер не отвечает?
1. Зайди на Render → выбери сервис
2. Посмотри **Logs** (последние строки)
3. Если видишь `❌ Failed to initialize DB` — БД заснула
4. Разбуди БД (Шаг 2) и перезапусти сервер (Manual Deploy → Deploy)

### Ошибка 503?
Сервер автоматически пробует переподключиться до 10 раз.
Подожди ~30 секунд и обнови страницу. Если не помогло — нажми «🔍 DB Status».
